## Documentation

Read the docs: https://dogeiscut.github.io/starfrootle/

To build them locally: install [mdBook](https://rust-lang.github.io/mdBook/) and run `mdbook serve docs`.

## Building

Nothing even compiles today, but with Rust 2024, you can attempt to build the project with

```sh
cargo build
```
